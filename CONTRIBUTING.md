# Contributing to Aura PM

Thanks for your interest in Aura PM.

- Use synthetic Salesforce examples unless real data is explicitly authorized.
- Never commit credentials, customer data, production exports, or confidential employer/client code.
- Treat AI review as advisory; verify findings and test claims.
- Do not enable an agent to merge or deploy changes autonomously.
- Include motivation, behavior changes, tests performed, and security/release implications in pull requests.
- Report sensitive security issues privately rather than posting secrets or exploit details in a public issue.
